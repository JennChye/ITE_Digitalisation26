# Optional private monthly reflection

## What students can review

The Monthly Reflection page lets students choose a month and look back at their private meal notes. It shows meals logged, days noted, different meals, explored swaps, an optional total estimate, and earned badges. The page uses supportive language and does not rank students or set targets.

Students can write, save, edit, or clear an optional private reflection note of up to 500 characters. The note is stored in the existing local private learning data.

## Privacy and feature control

The Dashboard has a Monthly reflection switch. Turning it off pauses the reflection page and shows a clear return to Dashboard controls. Reflection data, personal notes, meal history, badges, and swap activity are not added to Student Community, leaderboards, teacher moderation, or community posts.

## Manual testing steps

1. Open Dashboard and select **Open monthly reflection**.
2. Choose a different month. Check that only meal logs from that month are counted.
3. Enter a short private note and select **Save reflection**.
4. Return to the page and check that the note remains.
5. Select **Open badge collection** and check that badge details remain private.
6. Return to Dashboard, turn off Monthly reflection, and check that the Reflection page shows the paused state.

## Verification
