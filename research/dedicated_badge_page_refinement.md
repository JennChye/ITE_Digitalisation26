# Dedicated badge page refinement

## Achievement location

The Dashboard no longer shows achievement cards, badge progress bars, badge counts, earned cards, or locked cards. It only provides a compact **Open badge collection** entry beside private learning controls.

The private `/badges` page is now the single place where students can view earned badges and badges that remain available to explore. This page remains browser local and does not add badge information to Student Community.

## Manual check

1. Open Home and confirm that the Dashboard has no achievement card grid or badge progress summary.
2. Select **Open badge collection**.
3. Confirm the collection page displays **Earned** and **Continue exploring** sections.
4. Confirm the privacy note states that badges and progress are not shared with Student Community.
5. Turn off Learning badges on Home. Confirm the collection page shows **Badges are paused**.

## Mobile visual check

Home and `/badges` were checked at a 390 pixel mobile width. The Dashboard remains compact and the complete badge grid is shown only on the dedicated page without horizontal scrolling.
